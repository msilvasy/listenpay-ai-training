# Project Asset References

The login panel’s nurse photograph is supplied as a managed project asset and is referenced in the application at `/manus-storage/nurse_9ddd6c62.jpg`. The original staged file is maintained at `/home/ubuntu/webdev-static-assets/listenpay-programs/nurse.jpg` during this project session.

The source image is intentionally kept outside the web project directory to prevent static media from being included in the deployable source bundle. This keeps the downloadable application source lightweight while the app continues to reference the approved managed asset URL.
