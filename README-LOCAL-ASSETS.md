# Self-Contained ListenPay Angular Project

The source package includes all imagery under `src/assets/images/`, including the nurse image, ListenPay branding, worker imagery, and the four supplied category icons.

Install dependencies with `npm install`, then launch the application with `npm start`. Angular copies local assets to `/assets/images/` as part of both development and production builds; the project has no `/manus-storage/` dependency.
